# Guia de Ejercicios

¡Hola! ¿Qué tal?

Mi nombre es Godot y este repositorio tiene el fin de tener una guía de ejercicios de las materias de programación de la carrera de "Ciencias de la Computación".

## Estructura del Proyecto

El proyecto sigue un formato de carpetas estandarizado para mantener el orden y la facilidad de navegación:

1. **Materias (Carpetas Raíz):**
    * `Algoritmos_Y_Programacion`
    * `Algoritmos_Y_Estructura_De_Datos`
    * `Ingenieria_De_Software`
2. **Temas/Guías (Subcarpetas):** Formato `\d-Nombre_Guia` (ej. `7-Estructuras_Multienlazada`).
3. **Ejercicios (Archivos):** Formato `\d\d-Nombre_Ejercicio` (ej. `06-FibonacciRecursivo.cpp`).

# Materias incluidas

### 1. Algoritmos y Programación

Este es el ABC de la programación. Empiezas sin saben absolutamente nada para adentrarte a profundidad en el mundo de la programación, algoritmos, resolución de problemas y razonamiento lógico del mismo.

#### Se tratan temas como

* Acciones elementales

* Estructuras de control condicional
* Estructuras de control iterativo
* Arreglos y matrices
* Programación orientada a objetos (POO)

### 2. Algoritmos y Estructuras de datos

Habiendo dominado todo lo de **AyP** se encuentran con una nueva materia donde entenderan como se crean, manejan y estructuran los datos a tu conveniencia y otras técnicas de programacion.

#### Se tratan temas como

* Recursividad

* Backtracking
* Listas, pilas y colas
* Arboles

### 3. Ingeniería de Software

Aquí es donde dejamos de ser solo programadores que escriben código a ser programadores que crean y estructuran grandes proyectos y manejan de forma sólida las bases de la programación y una forma de trabajar en equipo y manejar proyectos.

#### Se tratan temas como

* Introducción a Git, Visual Code y UML

* Diagramas UML
* Modelo del Dominio
* Patrones de Diseño
* Pruebas Unitarias
